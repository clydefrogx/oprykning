# oprykning

A web page that shows which teams move up ("rykker op") in Herre Senior 4 7:7 Efterår. It reads the standings of the 8 pools from dbu.dk and ranks the teams across all pools. For each team it shows matches, points, points per match and goal difference per match. The 12 best eligible teams are marked as moving up, teams with a no-show are marked as not eligible, and one team (Union 9) is marked with a dot.

The page is rebuilt once a day at 00:00 Danish time and published with GitHub Pages.
